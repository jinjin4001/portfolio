# Jin Liu — Product Designer

Static portfolio website built with HTML and CSS.

## Preview locally

Open `index.html` in a browser or serve this folder with a local static web server.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages and select the `master` branch with the repository root as the publishing source. The site is plain static HTML and can be hosted on GitHub Pages without a paid hosting plan.

For a custom domain, add the domain in the Pages settings and configure the DNS records with your domain provider. Add a `CNAME` file with the chosen hostname after the domain is set.
